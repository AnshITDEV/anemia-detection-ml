# Anemia Detection using Machine Learning

## Project Overview
This project is an AI-based Clinical Decision Support System (CDSS) developed to detect anemia using patient blood test parameters. The system uses machine learning algorithms to analyze medical data and predict whether a patient is anemic.

## Features
- Predict anemia using blood parameters
- Machine learning model integration
- Web interface for input and prediction
- Fast and automated diagnosis support

## Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas
- HTML
- CSS
- Machine Learning

## Input Parameters
The system takes the following parameters:

- Age
- Gender
- Hemoglobin
- Mean Corpuscular Hemoglobin (MCH)
- Mean Corpuscular Hemoglobin Concentration (MCHC)
- Mean Corpuscular Volume (MCV)
- Red Blood Cell count (RBC)

## Workflow
1. Data Collection
2. Data Preprocessing
3. Model Training
4. Model Testing
5. Prediction through Web Interface
